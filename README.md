# အဓိပတိတိုင် နှင့် အာယုစန်း တွက်စက် (Adhipati & AyuSan Calculator)

မြန်မာ့ရိုးရာ နက္ခတ်ဗေဒင်ပညာရပ်နှင့် အာယုစန်းပညာရပ်ကို အခြေခံ၍ တိကျစွာ တွက်ချက်ပေးနိုင်သော Web-based Application တစ်ခု ဖြစ်ပါသည်။ ဤ Calculator သည် မွေးနှစ်အဓိပတိတိုင်ကို အခြေခံပြီး ယခုရောက်ရှိနေသော အချိန်ကာလ၏ ကံဇာတာ အနိမ့်အမြင့်ကို တွက်ချက်ဖော်ပြပေးပါသည်။

## ✨ အဓိက လုပ်ဆောင်ချက်များ (Features)

* အဓိပတိတိုင် တွက်ချက်ခြင်း: မွေးနှစ် (မြန်မာသက္ကရာဇ်) ကို အခြေခံ၍ အိမ်ကွက်ဌာန ၉ ခုကို အလိုအလျောက် ခင်းပေးခြင်း။
* နက္ခတ်ပေါင်းစပ်မှု: ပြည့်စန်းနှင့် စင်နက္ခတ်တို့ကို နက္ခတ်၊ ပါဒ်၊ လိတ္တာ၊ ဝိလိတ္တာ (၆၀-၄-၂၇ စနစ်) အတိုင်း တိကျစွာ ပေါင်းစပ်ပေးခြင်း။
* အာယုစန်း ဌာနစစ်ဆေးခြင်း: ရရှိလာသော အာယုစန်းနက္ခတ်သည် အဓိပတိတိုင်၏ မည်သည့်ဌာန (အဓိပတိ၊ အဓိယောဂ၊ ရာဇယောဂ၊ သီရိ၊ ယသ၊ ပုတိ၊ ဘင်္ဂ၊ မရဏ၊ သောက) တွင် ကျရောက်နေသည်ကို Highlight ပြသပေးခြင်း။
* ဟောကိန်းနှင့် ယတြာ: ကျရောက်သော ဌာနအလိုက် ကောင်း/ညံ့ ဟောကိန်းများနှင့် အညံ့ဌာနများအတွက် ဆောင်ရန်၊ ရှောင်ရန်နှင့် ယတြာများကို တစ်ပါတည်း ဖော်ပြပေးခြင်း။
* Responsive UI: Dark Gold Theme ဖြင့် ဖန်တီးထားပြီး Mobile နှင့် Desktop နှစ်မျိုးလုံးတွင် ကြည့်ရှုရ လွယ်ကူခြင်း။

## 🛠 အသုံးပြုထားသော နည်းပညာများ (Tech Stack)

* HTML5 - Structure ပိုင်းအတွက်
* CSS3 - Modern Dark UI နှင့် Layout ပိုင်းအတွက်
* JavaScript (ES6) - ဗေဒင်တွက်ချက်မှု Logic များအတွက်

## 🚀 စတင်အသုံးပြုပုံ (Usage)

၁။ ဤ Repository ကို Download (သို့မဟုတ်) Clone လုပ်ပါ။
၂။ index.html ဖိုင်ကို Browser တစ်ခုခုဖြင့် ဖွင့်ပါ။
၃။ မွေးနှစ်၊ ပြည့်စန်းနှင့် စင်နက္ခတ်တန်ဖိုးများကို ထည့်သွင်းပါ။
၄။ "တိုင်တွက်မည်" ခလုတ်ကို နှိပ်၍ ရလဒ်ကို ကြည့်ရှုနိုင်ပါသည်။
